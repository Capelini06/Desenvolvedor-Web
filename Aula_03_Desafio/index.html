Linguagem de marcação utilizada para definir a estrutura da página web.
CSS:
Linguagem de estilo utilizada para personalizar a aparência dos elementos.
Atributo Style:
Instrução usada dentro da tag HTML para aplicar regras de estilo diretamente no elemento
