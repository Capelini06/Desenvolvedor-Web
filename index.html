Trabalhando com Imagens em HTML e CSS

Nesta atividade aprenderemos como inserir imagens utilizando HTML e como modificar sua aparência utilizando diferentes propriedades CSS.

1. Inserindo uma imagem

Para inserir uma imagem em HTML utilizamos a tag <img>.

A propriedade src informa onde está o arquivo da imagem, enquanto alt fornece uma descrição do conteúdo

2. Comparando formatos de imagem

Uma mesma imagem pode ser salva em diferentes formatos. Mesmo mantendo a mesma resolução, o tamanho do arquivo pode mudar bastante.

Abaixo utilizamos a mesma imagem da academia, com resolução 1920x1080, salva em quatro formatos diferentes.

Formato AVIF

Resolução: 1920x1080
Tamanho do arquivo: 192.74 KB

Formato JPG

Resolução: 1920x1080
Tamanho do arquivo: 338.29 KB

Formato PNG

Resolução: 1920x1080
Tamanho do arquivo: 866.47 KB

Formato WEBP

Resolução: 1920x1080
Tamanho do arquivo: 247.56 KB

Observe: todas as imagens possuem a mesma resolução, porém o tamanho dos arquivos é diferente. Isso acontece porque cada formato utiliza características e técnicas diferentes para armazenar e comprimir a imagem.

Quanto menor o arquivo, menor tende a ser a quantidade de dados que o navegador precisa carregar. Por isso, escolher corretamente o formato de imagem também pode ajudar no desempenho de um site.
